## About Me

I build **AI-powered automation workflows** that connect language models, APIs, business logic, and everyday tools to solve practical operational problems.

My current focus is **n8n workflow automation, OpenAI integration, REST APIs, webhooks, JavaScript-based workflow logic, structured AI outputs, and human-in-the-loop systems**.

I focus on complete workflows rather than isolated AI demos — taking data from **intake → processing → validation → routing → storage → action**, with deterministic business rules and human review where appropriate.

### 📄 [AI Document Processing & Data Extraction](https://github.com/Khayest/ai-document-processing)

**AI-assisted invoice extraction, validation, and exception routing for document-processing workflows.**

Built an end-to-end n8n workflow that processes invoice PDFs, extracts structured invoice data using OpenAI, applies deterministic validation rules to financial fields, and automatically routes invoices based on validation results. Valid invoices are stored separately, while failed invoices are sent to a **human-review queue** with an automated review alert.

**Engineering highlights:**  
`PDF Extraction` · `Structured AI Extraction` · `Financial Validation` · `Conditional Routing` · `Exception Handling` · `Human Review`
